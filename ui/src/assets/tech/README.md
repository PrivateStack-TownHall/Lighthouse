# Technology logos

Drop one file per technology here, named by its library id. The UI picks them up automatically
(`features/configuration/tech-logos.js`); until a file exists, a monogram is shown.

| id | Technology |
|---|---|
| `javascript` | JavaScript |
| `typescript` | TypeScript |
| `react-vite` | React + Vite |
| `nextjs` | Next.js |
| `tailwindcss` | Tailwind CSS |
| `bootstrap` | Bootstrap |
| `express` | Express |
| `nestjs` | NestJS |
| `sequelize` | Sequelize |
| `prisma` | Prisma ORM |
| `mongoose` | Mongoose |
| `postgresql` | PostgreSQL |
| `mysql` | MySQL |
| `mongodb` | MongoDB |

Formats: `.svg` (preferred), `.png` or `.webp`, square, at least 64 × 64 px. Example: `postgresql.svg`.
